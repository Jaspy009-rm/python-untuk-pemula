# Python untuk Pemula

Repositori latihan belajar Python dari modul Santrikoding.

## Materi yang dipelajari
1. Hello World
2. Variabel dan Tipe Data
3. Operator
4. Kondisi If Else
5. Perulangan (for, while)
6. Lists dan Dictionaries
7. Function
8. Class dan Object
9. Package Installer (PIP)

## Cara menjalankan
1. Buat dan aktifkan virtual environment:
   python -m venv venv
   venv\Scripts\activate
2. Jalankan file, contoh:
   python hello.py

## Struktur
- `*.py` : contoh kode tiap materi
- `screenshots/` : hasil eksekusi program
- `catatan_pip.md` : catatan penggunaan pip
